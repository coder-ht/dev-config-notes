# Baseline 项目规则

本文件适用于 `/home/ghy/work/baseline` 和 `/home/hetao/workspace/baseline`。

## 权威入口与路由

- 先读取当前 checkout 中最近层级的 `AGENTS.md`、README 和目标配置；仓库尚无专项 Agent 入口时，以当前配置文件、Git 状态和实际校验结果为准。
- 前端部署版本以 `component/fe.yaml` 的目标 `package` 条目为基线事实；候选新版本必须从用户指定应用当前分支的 `package.json` 或该应用自己的权威版本文件获取，不能从历史记忆猜测。
- 版本升级任务按本项目 `experience.md` 的最小流程处理，不把单次应用清单或版本号写进规则。

## 个人补充与环境边界

- 只处理用户明确指定的应用；未指定目标、目标应用路径无法确认或版本来源冲突时先询问，不扫描后自行扩大升级范围。
- 应用仓库路径、分支和认证信息只从当前环境资料或用户明确输入获取，不把某台机器的绝对路径提升为跨环境规则。
- 只有用户明确要求时才暂存、提交或推送，并确保提交只包含本次目标配置。
