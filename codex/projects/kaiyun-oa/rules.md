## 权威入口与路由

- 仓库根 `AGENTS.md` 是项目规则入口；命中前端、后端模块或项目 Skill 后，继续读取最近层级 `AGENTS.md` 和对应 Skill。
- 前端以 `kaiyun-fe` 的当前 `package.json`、配置和源码为事实来源；后端以 `kaiyun-be` 的当前父 POM、模块 POM、配置和源码为事实来源，不在本文件固定模块依赖图、版本或单个业务接口。
- Git 快捷操作、集合工具等专项规则按仓库根 `AGENTS.md` 的 Skill 路由按需读取，不因普通任务固定加载。

## 个人补充与环境边界

- 不自动运行完整前后端构建；先根据改动范围做静态检查、模块级编译或针对性测试，用户明确要求时再扩大验证范围。
- Java 启动、Maven 依赖和 AI 库问题先核对当前 POM、实际依赖树和本机已安装 JAR，不按旧经验固定版本或包名。
- 服务器路径、环境含义和远程操作边界以仓库根 `AGENTS.md` 及当前部署配置为准；地址、凭据和机器状态只从当前环境资料获取，不跨环境复用。
- 业务约束保留在业务代码、文档或模块级规则中，不把考勤、集合实现或单个接口特例提升为项目全局规则。
